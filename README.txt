KILLEX
Проект и экосистема — Killex. Игра — «Герои Эфира».

Единственная рабочая копия игры: games/heroes-of-ether
Открой Killex.code-workspace в редакторе или games/heroes-of-ether/README.md.

ПАПКИ
games/heroes-of-ether/ — сервер, браузерная игра, правила, графика и тесты.
operations/ — обслуживание локальной игры и VPS; не игровые правила.
docs/ — документы проекта и готовые материалы.
artifacts/ — отчёты, измерения, скриншоты, исходные свидетельства проверок.
backups/ — проверенные резервные копии рабочих сохранений.
.cache/ — восстановимые браузерные среды для тестов.

КОМАНДЫ ИЗ ЭТОЙ ПАПКИ
npm start          — обычный запуск игры.
npm test           — серверные и модульные проверки.
npm run check      — связи между модулями, страницами и ресурсами.
npm run doctor     — диагностика конфигурации, процесса и сохранений.
npm run docs:refresh — обновление справочников из действующих правил.
Зависимости игры: npm --prefix games/heroes-of-ether ci

ГДЕ МЕНЯТЬ ПРАВИЛА
games/heroes-of-ether/README.md содержит ссылки на физику, бустеры,
кланы, цены, прогресс, окна и изображения.
Конфигурация запуска — games/heroes-of-ether/config.
Сохранения — games/heroes-of-ether/data; не редактировать при работающем сервере.
Локальная база и база VPS разные; копирование файлов проекта не объединяет их.

ХРАНЕНИЕ КОПИЙ
Killex/backups: три свежих комплекта плюс отдельно закреплённые важные копии.
Правило и причины исключений: operations/backup-retention.json.
npm run backups:prune — восстановить и проверить сохраняемые копии, показать план.
npm run backups:prune -- --apply — повторно проверить и удалить старые по плану.
После каждого создания и успешной проверки новой копии выполнять эту очистку
как заключительный шаг выпуска. Это обслуживающая команда, а не задача по таймеру.
Журнал проверки и удаления сохраняется в artifacts/backup-retention-*.
Рабочие data, материалы оптимизации в artifacts и одноразовая полная копия
рядом с Killex не входят в цели этой команды.

ИСТОРИЯ И СОВМЕСТИМОСТЬ
Старые рабочие названия не используются как название игры или модулей.
Имена действующих cookie, браузерных настроек и сетевого протокола сохранены
в shared/platform-contract.js, чтобы существующие профили не потеряли сессии.
Исторические отчёты и оригиналы рисунков сохраняют исходные названия.
Внешние папки лабораторий художников не входят в эту рабочую копию игры.
Прежний путь «Сферорумия» теперь только ссылка на Killex для совместимости
с открытым чатом и старыми ссылками. Второй копии игры в нём нет.
Для новой работы открывай Killex.code-workspace.

Одноразовая полная копия до упорядочивания находится рядом с Killex:
Killex-backup-20261113-0245. В ней есть SHA-256 каждого файла и отдельно
проверенные согласованные сохранения; файл verified.json содержит результат.
