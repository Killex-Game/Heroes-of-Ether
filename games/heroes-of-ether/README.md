# Герои Эфира

Проект и экосистема — **Killex**. Игра — **«Герои Эфира»**.

Локальная браузерная игра. Сервер отвечает за игровые правила и сохранения, браузер — за окна, ввод и рисование арены.

## Запуск

Открой PowerShell в папке с этим файлом:

```powershell
npm.cmd install
npm.cmd start
```

Игра: [http://localhost:3000](http://localhost:3000). Остановка — `Ctrl+C`. Нужен Node.js 20.19.0 или новее.
Для другого порта перед запуском задай `$env:PORT=3001`.

Для игры с других компьютеров в той же сети используй LAN-адрес, который сервер печатает при запуске, например `http://192.168.0.2:3000/`. Все данные сохраняются на компьютере с сервером. [Инструкция по локальной сети](docs/local-network-play.md).

## Проверки и обслуживание

```powershell
npm.cmd run config:check
npm.cmd run doctor
npm.cmd test
npm.cmd run check:structure
npm.cmd run format:check
npm.cmd run format
npm.cmd run docs:refresh
npm.cmd run test:browser:visual
npm.cmd run test:browser:clans
```

`config:check` проверяет настройки запуска без открытия профилей и подключения к базе. `doctor` дополнительно показывает процесс сервера, локальные файлы журнала, свободные ресурсы и свежесть синхронизации MongoDB. Пароли и содержимое профилей не выводятся. Для отдельной сетевой проверки Atlas: `node scripts/deployment/mongodb-health.cjs --atlas`.

`npm test` ограничивает параллельность двумя процессами тестов; при необходимости задай `TEST_CONCURRENCY` от 1 до 8. Это не нагрузочный прогон. Проверка структуры включает также служебные `.cjs` файлы.

Браузерные сценарии требуют Playwright и установленный Chrome. В среде Codex Playwright доступен через `NODE_PATH` встроенного Node runtime. Сценарии используют отдельные тестовые профили и свободный порт.

`npm run test:browser` проверяет текущую загрузку, существующую сессию, меню, покупку с задержанным ответом, защиту от повторного нажатия, гардероб, вход на арену, движение и выход через результаты. Для Firefox/WebKit передай имя движка; `KILLEX_BROWSER_EXECUTABLE` позволяет указать установленный браузер. Старый большой сценарий `test:browser:legacy` сохранён как исторический: он содержит прежние цены, состав меню и порядок выбора ника и пока не является приёмочным тестом текущей версии. Его прежний отказ воспроизведён и на исходной версии игры.

`npm.cmd run dev:bots -- status|on|off` управляет временными ботами. Команды выдачи тестовых валют и инвентаря находятся в `scripts/development`; их следует запускать при остановленном сервере.
