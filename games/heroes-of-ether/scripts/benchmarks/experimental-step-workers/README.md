# Эксперимент переноса игрового шага, 06.11.2026

Это изолированный прототип для измерений. Сервер игры его не импортирует.

Полный снимок комнаты передаётся worker, общий `Arena.step` выполняется там,
результат возвращается на синхронной границе. Профили остаются у основного
процесса; исходное состояние при отказе потока позволяет выполнить шаг один раз.
Это **не** независимые комнаты: основной поток ждёт общую границу.

Проверены все 30 типов бустеров, удерживаемые цели Вихря, порядок случайных чисел
и отказ потока. Однако нагрузочный тест 3 × 35 игроков + 30 в лобби показал
регрессию. Полное копирование состояния слишком дорого; v8-сериализация также
не дала выигрыша. Подключать прототип к рабочему серверу нельзя на основании
этих результатов. Путь дальнейшей архитектуры — постоянное владение состоянием
комнаты в worker и обмен командами/результатами транзакций, без полного
копирования мира на каждом шаге. Это требует отдельной проверки порядка
команд, подтверждённых списаний, завершения жизни и восстановления.

Результаты: `artifacts/arena-step-workers-20261106/` в корне рабочего каталога.
Проверки: `node --test tests/unit/arena-step-workers.test.js`.
