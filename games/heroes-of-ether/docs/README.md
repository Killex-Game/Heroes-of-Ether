# Документация игры

Начальная точка для работы с проектом — [README](../README.md).

- [Карта всех исходников](project-map.md): назначение каждого модуля.
- [Архитектура и соглашения](architecture.md): поток данных, порядок CSS и правила именования.
- [MongoDB HeroEther](mongodb-storage.md): подключённый Atlas, локальный журнал, проверка и восстановление сохранений.
- [Разбор советов по MongoDB и VK](architecture-advice-20261110.md): решения, изолированный стенд входа, проверки и дальнейшая миграция.
- [Ресурсы](assets.md): где находятся изображения и как они подключаются.
- [VIP-аватарки](vip-avatar-assets.md): размеры портретов, единый каталог путей и пересборка.
- [Арена](rules/arena.md): параметры массы, движения, деления и поглощения.
- [Бустеры](rules/boosters.md): каталог и действующие эффекты.
- [Кланы и лиги](rules/clans.md): настройки кланов, степени сундуков и лиги.
- [Опыт](rules/experience-and-levels.md): уровни и начисление опыта.
- [Достижения](rules/achievements.md): цепочки и степени.
- [Звания и сундуки](rules/titles-and-chests.md): пороги и награды.
- [Скины и аксессуары](rules/cosmetics.md): каталоги изображений и бонусы.
- [Список переименований](file-renames.json): соответствие старых и новых путей.
- [Проверка перестройки](refactor-verification.md): выполненные проверки и резервная копия.
- [Подготовка к запуску в VK на 400 игроков](../deployment/vk-production/README.md): выбор серверов, распределение арен, база данных и выключенные заготовки.

Справочники правил и карта модулей собираются из текущего кода командой `npm run docs:refresh`.

В `history/` сохранены прежние инструкции, предложения и отчёты. Они отражают состояние на дату соответствующего этапа; текущие правила находятся в `rules/` и исходных модулях по ссылкам из справочников.
