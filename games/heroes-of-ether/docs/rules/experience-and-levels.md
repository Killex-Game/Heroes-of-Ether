# Опыт и уровни

Справочник сформирован из текущего кода командой `npm run docs:refresh`.

Источник: [модуль правил](../../src/server/progression/experience-progression.js).

Килл даёт 3 опыта; повторный зачёт одной жертвы ограничен периодом 180 секунд. Начисление и ограничения проверяет сервер.

| Верхняя граница диапазона уровня | Опыт на ступень |
| --- | --- |
| 25 | 500 |
| 120 | 1000 |
| 500 | 3000 |
| 5000 | 5000 |
| 10000 | 10000 |
| Infinity | 15000 |

Удержание массы накапливает опыт и бонусные киллы по активным тактам, с выдачей каждые 30 секунд. База киллов: 5. При общей массе меньше 30 000 за полный такт выдаются 25 × k опыта и 5 × k киллов; от 30 000 включительно: 75 × k + n опыта и 5 × k + n киллов. k = 1 без аккаунтов, 2 с VIP, 3 с Premium или обоими аккаунтами. n - число живых участников своей комнаты, включая самого игрока и ботов; части, погибшие игроки, лобби и оставшиеся модели не увеличивают n. Изменения массы, аккаунтов и числа участников учитываются только за наблюдавшееся время, без пересчёта прошлого. Незачисленный пакет сгорает при завершении жизни; дробный остаток переносится только внутри жизни. Паузы без активных тактов не оплачиваются. Бонусы подарков и экипировки, предел опыта и реальные поглощения сохраняют прежние правила. Реальное поглощение даёт 3/6/9/9 опыта и один килл.

За один вход на арену можно накопить опыт до следующего уровня. При завершении жизни опыт зачисляется в профиль. За каждый полученный уровень сервер выдаёт 10 монет и 1 кристалл однократно, без множителей аккаунта; награда видна в уведомлении «Уровень повышен».

При достигнутом лимите окно итогов показывает полную шкалу и новый уровень; в лобби показан реальный прогресс к следующему уровню. Продолжение жизни сохраняет лимит. Для нового начисления нужно выйти в лобби и снова нажать «Играть».
