# Тестовые покупки за голоса

Справочник сформирован из текущего кода командой `npm run docs:refresh`.

Источник: [модуль правил](../../public/shared/virtual-product-catalog.js).

Локальная симуляция: настоящие деньги и голоса не списываются. Отмена, крестик и Escape до подтверждения ничего не начисляют.

Подтверждение сохраняет валюту или 7 дней VIP/Premium в серверном профиле. Пакеты включают бонус и не умножаются статусами. Продление сохраняет оставшийся срок; истёкший аккаунт начинается от текущего времени.

Каждая новая подтверждённая покупка, включая повторную покупку того же продукта, учитывается в достижениях. Монеты — «Богач», кристаллы — «Шахтер», эфир — «Банкир»; считается весь пакет с бонусом. VIP/Premium добавляют неделю в свою цепочку. Отмена не меняет прогресс.

Повтор номера операции не выдаёт товар дважды, включая перезапуск сервера. При потере ответа нажми «Проверить операцию». Номер сохраняется в текущей вкладке и восстанавливается после перезагрузки при открытии того же товара. Покупки доступны только в лобби, включая LAN HTTP.

API симуляции: `POST /api/mock-payments/confirm`, поля `productId`, `requestId`, `confirmed: true`. Получатель определяется сессией, цена и количество — каталогом. Перед настоящими платежами тестовый API надо отключить и заменить выдачу проверенным серверным уведомлением провайдера.
