# Индикаторы меню и сундуки за задания

Красная точка справа сверху кнопки плавно пульсирует; системное снижение анимаций отключает пульсацию. Размеры всех девяти кнопок меню одинаковы.

Новые предметы инвентаря, оформления, аксессуары, питомцы и их уровни, полученные степени достижений и новые доступные товары отмечаются относительно последнего состояния. Прочтение сохраняется в браузере отдельно для каждого профиля. Старое содержимое при первом запуске не помечается целиком как новое. Открытие соответствующего окна снимает отметку о новинках.

Завершение задания автоматически создаёт сундук в постоянном списке `quests.pending`; этот список отображается в «Инвентарь → Сундуки → Сокровищница». Дополнительного переноса и повторного расчёта приза нет. Старые неоткрытые сундуки тоже отображаются там. Эти сундуки не занимают ограниченные места клановых сундуков и не имеют срока открытия. Карточки имеют одинаковый размер и страницы вместо новой прокрутки.

У «Заданий» индикатор снимается после просмотра выполненного задания. У «Инвентаря» он остаётся, пока есть доступные неоткрытые сундуки. Открытие сундука за задание использует существующую атомарную операцию с квитанцией: повторный запрос не начисляет приз дважды, ошибка сохранения не расходует сундук. Билеты определены при выполнении задания; завершение ивента их не удаляет.

У «Клана» индикатор заявок показывается только при серверном праве на приём: главе, управляющему, офицеру, с учётом испытательного срока. Обычным участникам количество заявок не раскрывается. Обновляется с профилем и через существующий heartbeat каждые 20 секунд, даже при закрытом окне клана. Доступные клановые награды также требуют внимания. У «Топов» точка показывает непрочитанные уведомления о наградах.

Пять вращений рулетки доступны любому игроку за пять билетов при открытом ивенте и нахождении в лобби. Lite требуется для быстрой прокрутки и покупки билетов; пакет ×5 больше не заявлен как преимущество Lite. Сервер атомарно сохраняет пять отдельных призов и одно списание пяти билетов.
