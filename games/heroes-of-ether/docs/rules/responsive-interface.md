# Адаптивный интерфейс

Справочник сформирован из текущего кода командой `npm run docs:refresh`.

Источник: [модуль правил](../../public/styles/layout/responsive-interface.css).

Элементы переносятся по ширине, а содержимое окон прокручивается по высоте. Автоматическое уменьшение сцены и окон через CSS zoom отключено. На экранах до 960 px лобби перестраивается; до 620 px меню распределяется в две колонки, панели клана — в одну. Зелёные кнопки «Играть» и «В бой» используют исходную золотую окантовку. Витрина достижений определяет число колонок по своей ширине и показывает до двух заполненных рядов. В каждом разделе валют восемь карточек: шесть пакетов и два ежедневных бонуса; сетка 4×2 переходит в две колонки до 1100 px и одну до 540 px.

Проверка: `npm run test:browser:responsive`, `npm run test:browser:firefox`, `npm run test:browser:edge`, `npm run test:browser:webkit`. Нужны Playwright и установленные тестовые браузеры. Матрица включает обычные экраны и размеры области браузера, соответствующие увеличенному масштабу 125–200%. WebKit проверяет движок Safari; отдельный запуск настоящего Safari на macOS/iOS остаётся дополнительной проверкой устройства.
