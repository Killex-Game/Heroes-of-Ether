# Эмблема окна доступа

`public/assets/ui/svg/identity/access-lock.svg` — оригинальная векторная иллюстрация,
созданная для Сферорумии 22.10.2026. Нарисована в SVG: литой золотой замок,
синяя эмаль, растительные завитки и блики металла. Внешние изображения,
шрифты, библиотеки и чужие торговые знаки не использованы.

Прозрачный холст 96×96. Показывается в размере 68×68 на компьютере и 56×56
на узком экране. Цвет и объём заданы в самом SVG; декоративный круг вокруг
прежней пиктограммы удалён. Внешняя атрибуция для этого рисунка не требуется.
