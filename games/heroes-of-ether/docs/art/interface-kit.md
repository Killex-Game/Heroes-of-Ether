# Интерфейс: UI Collection 01

## Горизонтальный каркас — 19 октября 2026

`public/styles/layout/responsive-viewport.css` загружается последним и отвечает за геометрию;
исходные тематические стили и изображения сохранены. Лобби использует HTML/CSS Grid:
профиль и три равные валютные плашки, строка прогресса, затем три колонки
«баннеры / аватар с аксессуарами и входом / меню». Форма входа находится внутри
центральной колонки. Высота сцены ограничена доступным экраном; вертикальной
перестройки лобби на телефоне больше нет. Для низкого альбомного экрана интервалы
уменьшаются, для совсем узкого окна целиком масштабируется горизонтальная сцена.
В портретном окне сохраняется её предварительный вид и подсказка о повороте.
Лобби является позиционированным контейнером для сцены. Расчёт масштаба
опирается на clientWidth/clientHeight, чтобы мобильный браузер не расширял
layout viewport и не переносил его увеличение на арену.

`public/ui/layout/viewport-layout.js` размещает существующие узлы семи основных окон
в одинаковые блоки `interface-header / toolbar / content / footer`, сохраняя
обработчики и ссылки компонентов. Размер окна фиксирован относительно экрана,
заголовок, основные вкладки и нижние действия не прокручиваются. Содержимое
прокручивается отдельно со стабильным резервом под полосу прокрутки.
Подтверждения, получение сундуков и игровой HUD сохраняют собственные формы.
Вкладки нарисованы CSS-рамками на всю ширину своей ячейки: выбранное состояние
не меняет их размеров. Малые альбомные размеры предполагают мышь/касание;
прежнее общее утверждение о минимуме 44 px не относится к компактному лобби.

Перед изменением создан и проверен архив
`../../backups/sferorumiya-before-horizontal-ui-20261019-023702.zip`:
702 файла, SHA256 `8E08267F2B6565A756E6CE2C2F84DD3ED39915C56A45E25E85B2BD1529AD699A`.
Для отката только этого оформления достаточно восстановить из него
`public/index.html`: он перестанет подключать новые interface-layout.css/js
и вернёт прежнее расположение формы входа. Профили, серверную блокировку
и игровые данные при таком откате восстанавливать не нужно.

Источник — предоставленный пользователем ui_catalog.html. Его копия лежит в
design/ui_catalog.html и не менялась. scripts/assets/import-interface-kit.js извлекает JSON KIT,
не выполняя демонстрационный JavaScript. Команда: npm.cmd run import-ui.
Подключение готово, запускать импорт для обычной игры не требуется.

В public/assets/ui сохранены 80 исходных SVG, четыре круглых PNG-аватара,
два рисованных PNG-герба и три демонстрационные SVG-иконки предметов.
manifest.json содержит размеры, безопасные области и cap_insets автора.
Все 89 изображений совпадают с вложениями каталога байт в байт.

## Применение в прототипе

| Пресеты                                         | Экран и поведение                                                                        |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------- |
| player_card_default, avatar_frame_*             | Профиль и миниатюры четырёх существующих скинов в лобби; круглые маски, живое имя        |
| button_primary/secondary/tertiary/danger, tab_* | «Играть», меню, покупки, выбор слотов, вкладки и выход; реальные disabled и aria-pressed |
| button_round__, icon_gear/close/chevron__       | Настройки, закрытие окон и смена скина; область нажатия не меньше 44 px                  |
| currency_coin/crystal                           | Только текущий серверный баланс, отдельные текстовые значения                            |
| window_large/compact, section_panel             | Магазин, инвентарь, настройки и карточки бустеров                                        |
| input_default/focus, toggle_on/off/disabled     | Имя, поиск, показ массы и полноэкранный режим                                            |
| item_slot_common/advanced/rare, item_overlay_*  | Редкость, количество, выбор, недоступность и ожидание серверной перезарядки              |
| player_row_*                                    | Серверные имена и масса в лидерах; компактный список на телефоне                         |
| avatar_*, clan_astral/grove                     | Круглые скины на арене, гербы при создании клана и в рейтинге                            |

Оформление — public/styles/theme/game-controls.css. Имена, описания и значения не вшиты в картинки.
Окна и кнопки используют border-image с областями растяжения из каталога.
Для профиля, круглых рамок и слотов сохранены пропорции. Сообщения остаются
настоящими HTML-элементами со статусами для доступности. SVG не управляют логикой.

Кланы используют два герба, общие кнопки, рамки и панели набора. Скины на арене
рисуются круглыми PNG-версиями тех же четырёх персонажей, подпись — в центре.
Плашки над игроком сохранены как ресурс, но больше не используются.
Полоса опыта использует progress_fill_xp.svg; окно достижений — существующие
рамки и панели. Пресеты чата, чекбоксов и слайдеров доступны для дальнейшей разработки.
Кланы, опыт и баланс берутся с сервера; демонстрационные значения не добавлены.

Покупки запрещены сервером для профиля на арене, включая другие вкладки.
Инвентарь и выбор слотов доступны в лобби; на арене — применение выбранных бустеров. Поглощение,
формула floor(масса * 80 / 100), серверные эффекты и мобильное управление сохранены.
Новых библиотек, платных сервисов и декоративных анимаций нет.

Макеты пакетов монеток, кристаллов и эфира открываются круглыми плюсами
возле соответствующих балансов. public/ui/shop/currency-purchase-dialog.js содержит по шесть
согласованных пакетов каждой валюты (18 всего); public/styles/components/currency-purchase-dialog.css
использует существующие рамки section_panel и window_large, круглые кнопки
и недоступную кнопку покупки. На узком экране карточки идут одной колонкой.
Оплата, HTTP-запросы покупки и изменение баланса в этом макете отсутствуют.
Окно закрывается крестиком или Escape с возвратом фокуса к плюсу; открытие
из магазина/инвентаря сохраняет исходное окно и выбранную вкладку.
В окне есть вкладки «Монетки», «Кристаллы», «Эфир»: плюс выбирает начальную
валюту, затем её можно менять без закрытия. Вкладки доступны касанием,
клавишами стрелок, Home и End; закрытие возвращает фокус к исходному плюсу.

Выход с арены использует отдельный диалог подтверждения и существующее окно
итога жизни. При добровольном завершении строка поглотившего игрока скрыта.
Кнопки, рамки, шкала опыта и мобильная компоновка соответствуют UI-набору.
