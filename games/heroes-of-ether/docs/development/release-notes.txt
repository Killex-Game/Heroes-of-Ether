Публичные версии «Герои Эфира» / Killex

Текущая версия интерфейса: Alfa-test 0.0.45.
Единый список изменений: public/shared/release-notes.js.

Для каждого публичного выпуска:
1. Обновить id, version, date и changes в этом файле; предыдущий выпуск перенести
   в KillexReleaseArchive. Включать только проверенные изменения,
   которые действительно выпускаются. Не объявлять устранение лагов без измерений.
2. Синхронизировать резервный текст версии .lobby-foot в public/index.html и обновить
   параметры версий ссылок на изменённые скрипты и стили, включая manifest.
3. Проверить новое окно после начальной загрузки, повторное открытие из «Новостей»,
   отсутствие повторного автоматического показа после закрытия и мобильную геометрию.
4. Сохранить прежние файлы и хеши, применить проверенный выпуск, сверить HTTP-хеши.

Окно «Что нового» открывается только в готовом лобби, когда нет другого окна
или обязательного выбора имени. Прочтение запоминается по игроку и версии в
localStorage данного браузера. На другом устройстве или после очистки хранилища
окно будет показано снова. При недоступном localStorage закрытие помнится в текущей
вкладке. Повторное открытие: «Новости» под «Питомцами», плашка «Обновления».
Газета реализована в public/ui/lobby/game-news.js. У статей показывается дата без
времени; номер версии находится внизу статьи выпуска.
