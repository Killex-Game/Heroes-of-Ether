# Игра по локальной сети

1. На компьютере с игрой запусти `npm start` из папки проекта.
2. На этом компьютере можно открыть `http://localhost:3000/`.
3. На остальных компьютерах в той же сети открой один из адресов, напечатанных сервером при запуске, например `http://192.168.0.2:3000/`.
4. Сервер должен оставаться включённым. Другим компьютерам нужны только браузер и доступ к этой сети.

`localhost` на каждом компьютере означает его самого. Для общей игры используй адрес компьютера с сервером. WebSocket подключается к тому же адресу автоматически.

Каждый браузер получает отдельный профиль. Все профили, балансы, кланы и результаты сохраняются сервером в `data/profiles.json`. На клиентах хранится cookie, связывающая браузер с его профилем. Очистка cookie или переход между `localhost` и IP-адресом создаст другой профиль в этом браузере; для одного профиля используй один и тот же адрес.

Если Windows блокирует входящие подключения, открой PowerShell от администратора в папке проекта и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\network\allow-local-players.ps1
```

Правило разрешает Node.js принимать TCP-подключения на порт 3000 только из локальной подсети. Проброс порта на роутере не требуется. Гостевая Wi-Fi сеть с изоляцией устройств не подходит — компьютеры должны иметь доступ друг к другу.

При изменении адреса компьютера с сервером используй новый адрес из его вывода. Данные при этом остаются в той же папке. Для постоянного адреса можно закрепить IP компьютера в настройках DHCP своего роутера.
