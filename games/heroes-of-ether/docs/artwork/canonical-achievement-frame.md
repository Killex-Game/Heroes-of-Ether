# Единая рамка достижений

По просьбе владельца от 23.10.2026 рамка больше не перерисовывается генератором для каждой иконки. Единый мастер: `public/assets/achievements/template/canonical-gold-frame.png`. Это исходные пиксели каноничной рамки «Лучшего Хозяина» из `public/assets/achievements/illustrated-v2/pet_master.webp`, с удалённой серединой по `interior-mask.svg`. Внешняя прозрачность сохранена. Сторонних изображений не добавлено.

Новая иллюстрация готовится без рамки на прозрачном холсте 256 × 256. Смысловой объект располагается внутри области маски, примерно x=40…216, y=36…205. Чтобы предмет не обрезался, оставлять небольшой внутренний отступ. Подложка может иметь любую подходящую палитру.

Сборка: `node scripts/artwork/compose-achievement.cjs illustration.png public/assets/achievements/illustrated-v2/achievement_id.webp`. Скрипту требуется библиотека sharp в окружении инструмента сборки; игровой сервер от неё не зависит. Он обрезает середину по общей маске и накладывает один мастер рамки сверху. Итог сохраняется в lossless WebP, поэтому внешний металл у разных иконок одинаковый. Вход и выход должны быть разными файлами; исходник иллюстрации хранить отдельно.

В этом обновлении рамка заменена у Карьеры, Царя, Толстяка, Максимума, По назначению, Щедрого и Не жалко. Середины взяты из их прежних проектных иконок, старое внешнее обрамление исключено маской. Применена детерминированная обработка sharp по прямому указанию владельца; генерация изображений не использовалась. Предыдущий аудит происхождения исходной игровой графики остаётся отдельной задачей перед коммерческим выпуском.

После сборки проверять иконку в размере 48–80 px, прозрачный внешний контур, отсутствие обрезанного предмета и старой двойной рамки. Во всех интерфейсах использовать один путь из общего каталога. При нулевой степени приглушать целиком готовый значок вместе с рамкой.
