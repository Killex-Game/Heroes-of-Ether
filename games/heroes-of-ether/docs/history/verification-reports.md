## Границы проверки

Это локальный прототип. Эмуляция мобильного экрана не заменяет проверку на
физическом смартфоне. Аппаратный полный экран, мобильная сеть, долговременная
нагрузка и восстановление после отключения питания в этот прогон не входят.
Полноэкранный режим по-прежнему использует существующий API браузера.

Профили сохраняются на диск в одном процессе сервера. Привязка к браузеру —
гостевая cookie, не регистрация с паролем. Удаление cookie даёт новый профиль.
Новые серверные зависимости и платные сервисы не добавлялись. Для обычного
npm.cmd test Playwright и браузерные пакеты не требуются.

## Повторение

npm.cmd test
npm.cmd start

Открыть http://localhost:3000. Для двух игроков использовать обычное и приватное
окно или два браузера. Для отдельного сквозного прогона при доступном Playwright
и Chrome выполнить npm.cmd run test:browser. Путь к уже установленному пакету
можно передать через NODE_PATH. Скрипт не устанавливает и не скачивает браузеры.
