Канон нагрузки
Весь замер состоит из последовательных смешанных минут. Клиенты постоянно
двигаются, делятся каждые 3.7 с, кормят W каждые 0.7 с, каждые 2 с пробуют
бустер и каждые 5.3 с эмоцию. Проверяется фактическое выполнение разделений
и кормления сервером, а не только число отправленных нажатий. Все 30 готовых
обычных/клановых бустеров должны успешно применяться в каждой минуте.
Пять клиентов лобби каждые 1.5 с выполняют цикл операций настоящего API:
профиль, рейтинг, комплектация, покупка, бонусы, подарки/прочтение, создание
кланов, казна, клановые бустеры, редактор, просмотр клана, рулетка, покупка/
выбор питомца, корм, чат, новости и присутствие. Средства выдаются только
в исходном синтетическом мире. Ошибки API не засчитываются как успех.
Пример: CAPACITY_REALISTIC=1 CAPACITY_MIXED_MINUTES=3
CAPACITY_PROTOCOL=sferorumiya-state-v10 node scripts/benchmarks/postgresql-capacity.cjs
PRIVATE_CONFIG NEW_PRIVATE_OUTPUT_DIRECTORY 2
Последний аргумент — количество комнат по 30; тест создаёт отдельную случайную
схему PostgreSQL. Нельзя указывать рабочий каталог данных в качестве output.

База: установленный backend 350a63a, 1280 синтетических профилей/128 кланов,
квота 3 CPU включает генераторы; рядом работающая игра имеет квоту 6 CPU.
30 арена + 5 лобби, 3 минуты: 20.08–20.23 Гц, tick work p95 19.11–19.86 мс,
2949 ACK восстановлены, PG=WAL, все проверяемые действия без ошибок.
60 + 5: первая минута не прошла (18.98 Гц и state gap p99 >150 мс), следующие
19.68–19.70 Гц; tick work p95 30.59–32.08 мс. 5477 ACK восстановлены, PG=WAL.
90 не запускали после отказа на 60. Это не максимальный CCU и не долгий soak.
Первый ошибочный стенд без события рулетки сохранён и исключён из приёмки.

Профиль CPU отдельного диагностического прогона 60 + 5:
физика 12.79 с/мин, подготовка/передача снимков 4.82 с/мин,
applyArenaProgress 5.42 с/мин (перекрывающиеся включающие измерения не суммировать).
Диагностика влияет на тайминг. Найдена глобальная пересылка полных профилей
после каждого действия клана. Кандидат адресного обновления проходит проверки;
на момент этой записи backend не заменён. Полный цикл и новая лестница в работе.

Данные: каталог premium-realistic-20261124 рядом с этим файлом.
