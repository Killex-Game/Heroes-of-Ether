# Аватарки Золотого набора VIP

В наборе пять портретов: Король, Королева, Принц, Рыцарь и Грифон.
Сохранённые ID `vip-1`…`vip-5` остаются прежними.

Исходники находятся в `public/assets/skins/vip-*.png`: квадратные PNG 1254 × 1254 с прозрачностью. Прежние ссылки на отсутствующие SVG заменены корректными путями.

Для каждого портрета подготовлены WebP в `public/assets/skins/vip/{размер}/`. Прозрачность сохранена; оригиналы не перезаписываются.

| Размер | Применение                                                            |
| ------ | --------------------------------------------------------------------- |
| 64     | Маленький профиль, списки клана и топов                               |
| 128    | Плотные экраны для маленьких аватарок, карточки набора, чужой профиль |
| 256    | Плотные экраны для карточек, превью выбранного скина                  |
| 512    | Крупный портрет в лобби и гардеробе                                   |
| 1024   | Крупные портреты на плотных экранах и текстура на арене               |

25 вариантов занимают вместе около 1,85 МБ; отдельная миниатюра 64 × 64 — около 4 КБ. Один исходный PNG занимает около 2,1–2,3 МБ.

Пути централизованы в `public/shared/player-identity.js`. `skinSource` подбирает размер, а `setSkinImage` назначает `src` и `srcset`. При переключении на обычный скин прежний VIP-источник удаляется. Топы, участники клана и чужой профиль используют общий компонент `public/ui/profile/public-player-dialog.js`.

Пересборка:

```powershell
npm.cmd run build:vip-avatars
```

Как и остальные инструменты графики в проекте, команда требует `sharp`. В среде Codex он доступен через `NODE_PATH` встроенного Node runtime. Генерация выполняется из имеющихся PNG и сохраняет исходную композицию.

Проверки:

```powershell
npm.cmd test
npm.cmd run check:structure
npm.cmd run test:browser:vip-avatars
```

Браузерный сценарий проверяет все пять скинов в наборе, лобби, гардеробе, топах, клане, профилях и рисовании Canvas. Также проверяются загрузка без ошибок, экран 320 px и DPR 2. Скриншоты и лог: `tests/artifacts/vip-avatar-*` и `tests/artifacts/vip-avatars-arena.png`.
