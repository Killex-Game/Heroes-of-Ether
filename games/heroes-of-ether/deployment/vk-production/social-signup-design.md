## Путь игрока

1. Игрок запускает игру в VK или Одноклассниках. При первом подтверждённом запуске игра автоматически создаёт один профиль. При следующих запусках, включая другое устройство, открывается тот же профиль.
2. Сервер выбирает обработчик площадки по настроенному идентификатору приложения. Обработчик проверяет подлинность данных запуска, соответствие приложению и действительность авторизации согласно документации конкретного способа публикации. Анонимный запуск не создаёт привязку. Данные подписи, секреты и токены исключаются из журналов.
3. Сервер ищет запись по трём полям: площадка, приложение, постоянный идентификатор пользователя. Создание профиля с внутренним UUID и привязки происходит в одной транзакции с уникальным ограничением на эту тройку. Два одновременных запуска получают один профиль. Повтор запроса после потери ответа возвращает существующий профиль без повторной выдачи стартового баланса.
4. После проверки сервер выдаёт собственную защищённую сессию. Прогресс, покупки и серия ежедневных бонусов принадлежат внутреннему UUID. Вход через другую сеть с совпадающим ником или числовым ID создаёт отдельную идентичность. Объединение аккаунтов потребует подтверждения обеих учётных записей. Перенос гостевого профиля также должен требовать явного выбора и проверки владения.

## До подключения

Получить тестовые идентификаторы приложений и зафиксировать конкретный формат запуска для каждой площадки. Проверить подделанную подпись, чужое приложение, просроченный или повторно использованный билет, анонимного пользователя, одновременный первый вход, смену устройства и выход из сессии. На тестовом стенде секреты хранятся отдельно от клиента. Подключение боевых маршрутов и миграция действующих игроков требуют отдельного решения.

Одноклассники указывают, что новые приложения создаются через инструменты VK. Возможность публикации и формат подтверждения личности нужно сверить для выбранной карточки игры. [Параметры запуска ОК](https://apiok.ru/dev/app/) · [Анонимный запуск ОК](https://apiok.ru/apps/game_setup/anonymous_games). Для VK выбор формата игры и проверка запуска уже описаны в [проекте интеграции](developer-guide.md).
