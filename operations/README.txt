ОБСЛУЖИВАНИЕ KILLEX / «ГЕРОИ ЭФИРА»

scripts/                 служебные сценарии локального компьютера.
scripts/vps-admin/       защищённый SSH-туннель панели владельца.
remote/ssh.cjs           выполнение подготовленных сценариев VPS с проверкой ключа сервера.

Игровые команды обслуживания находятся внутри игры:
games/heroes-of-ether/scripts/deployment/maintenance.cjs
games/heroes-of-ether/scripts/deployment/mongodb-health.cjs
games/heroes-of-ether/scripts/deployment/mongodb-data.cjs

В корне Killex: npm run doctor и npm run config:check.
Локальный запуск: npm start. Запускатель использует отдельный исправленный
Node.js из operations/runtimes/node-v24.22.3-win-x64, если он установлен.
При отсутствии этой копии нужен системный Node.js не ниже 24.22.3.
Среда Codex и глобальный Node других приложений не заменяются.
На VPS версия Node закреплена отдельным ExecStart игрового сервиса.
Панель владельца: раскрыть «Производительность» для ручного снимка метрик.
Она показывает интервалы тактов, задержки цикла и очереди; лимит игроков
в конфигурации сам по себе не означает подтверждённую вместимость.

Локальная игра и VPS имеют разные источники данных Atlas. Не копировать
profiles.json, WAL или MongoDB-конфигурацию одной стороны поверх другой.
Рабочий процесс Node не запускать с inspector: прежняя диагностика
сопровождалась падением. CPU-профили снимать на изолированном стенде.

Старые сценарии выпусков лежат в artifacts/ вместе со своими результатами.
Это свидетельства конкретных прогонов, а не команды для запуска наугад.
