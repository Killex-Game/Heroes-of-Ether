# Герои Эфира

Браузерная игра Killex. Код и игровые ресурсы: `games/heroes-of-ether`.

## Локальная разработка

Node.js >=24.22.3. Из корня репозитория:

```sh
npm run setup
npm --prefix games/heroes-of-ether ci
npm test
npm run check
npm start
```

`setup` создаёт только отсутствующий приватный конфиг владельца; существующий
не меняет. Без `config/mongodb.local.json` используется отдельное локальное
хранилище. Рабочая база VPS, доступы и реальные аккаунты сюда не копируются.
Подключение production Atlas не требуется для обычных тестов/разработки.

## Ветки и выпуск

Первый `main` содержит проверенный код работающего VPS `20261121-kill-review`.
Источники кода, публичные ресурсы и тесты сверены по SHA256. Машинные настройки
могут различаться: они не являются данными игроков и не заменяются при выпуске.
Ветка `work/local-unreleased-20261121` сохраняет найденные локальные отличия:
экспериментальные модули, тесты и рисунок эфира. Она не установлена на VPS.

Перед сменой сверять ветку, commit и текущий установленный release.
Изменения: отдельная ветка → проверки → согласованное слияние → установка
конкретного commit на VPS. Пока нет автоматического production-deploy.
Не запускать второй писатель на рабочей базе и не править сохранения вручную.
Миграции/перезапуски требуют резервной копии, проверки восстановления и
сохранения независимой админки. Подробности: `docs/repository-handoff.txt`.

Перед публикацией: `npm run repo:check`. Проверка читает именно Git-индекс;
она не заменяет ревью, аудит истории и полноценный поиск секретов.
В репозитории нет data/WAL, admin-control, ключей, паролей, runtime-бинарников,
полных отчётов и временных изображений. Текущие игровые изображения в
`public/assets` включены; крупные исходники рисунков хранятся отдельно,
их описания/промпты/происхождение остаются в текстовой документации.

## Архитектура

Цель: два миллиона зарегистрированных аккаунтов, а не одновременных игроков.
Разбор текущих ограничений и план развития на имеющемся оборудовании:
`docs/scaling-two-million-accounts.txt`. Это план, не обещание измеренной ёмкости.
Индекс игровых модулей: `games/heroes-of-ether/README.md`.
